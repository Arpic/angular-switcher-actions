# Angular Switcher Actions


<!-- Plugin description -->
**Angular Switcher Actions** is an IntelliJ plugin that introduces actions for switching to commonly used file types in angular project:
<ul>
    <li>Templates (html, svg)</li>
    <li>Components (js, ts)</li>
    <li>Tests (spec)</li>
    <li>Style (css, scss, less, styl)</li>
</ul>
<!-- Plugin description end -->
